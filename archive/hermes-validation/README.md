# Hermes Validation Archive

This directory preserves the retired numbered validation work: the former
single-agent acceptance stack, the Hermes-parent experiment, their compose
files, scripts, tests, reports, and legacy Discord notes.

It is not deployed by the current Freyja architecture. Names and paths inside
the archive are intentionally preserved so old evidence remains traceable.
The active design is documented in `docs/architecture/freyja.md`.
